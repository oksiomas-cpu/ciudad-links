# ciudad-links

Ссылки-редиректы со счётчиком переходов для **La Ciudad de los Sentidos**.

## Как работает
- `/g1`, `/g2` … `/g10` — человек жмёт, его сразу перекидывает на канал, клик тихо считается
- `/stats` — красивая страница со статистикой переходов (только для Оксаны)

Счётчики хранятся в `counts.json` прямо в этом репозитории — никаких баз подключать не нужно.

## Подключение к Vercel (один раз)
1. Зайти на vercel.com под своим аккаунтом
2. Add New → Project → импортировать репозиторий `ciudad-links`
3. В Environment Variables добавить одну переменную:
   - Name: `GH_TOKEN`
   - Value: токен GitHub (с правом записи в репозиторий)
4. Deploy

После этого ссылки живут по адресу `<проект>.vercel.app/g1`, статистика — `/stats`.
